# Доменная, SEO- и GEO-архитектура

Дата аудита: 28 июля 2026 года.

## Каноническая архитектура

Основной адрес проекта:

`https://печатаетмаксим.рф/`

Техническое имя этого же домена:

`https://xn--80aaarctnodv3agc9d.xn--p1ai/`

Домен `print86.ru` используется только как короткий латинский адрес и постоянно
перенаправляет на основной домен с сохранением пути и параметров запроса.

Это решение сохраняет уже работающий production и точное совпадение домена с
названием бренда. `print86.ru` удобнее диктовать латиницей, но название не
идентифицирует бренд и код региона `86` ограничивает восприятие проекта при
масштабировании за пределы ХМАО.

## Зафиксированное состояние

| Ввод пользователя | Состояние 28.07.2026 | Требуемое поведение |
| --- | --- | --- |
| `http://печатаетмаксим.рф/` | открывается основной HTTPS | один 301 на основной HTTPS |
| `https://печатаетмаксим.рф/` | работает | 200, каноническая версия |
| `http://www.печатаетмаксим.рф/` | открывается HTTPS-версия с `www` | один 301 на основной HTTPS без `www` |
| `https://www.печатаетмаксим.рф/` | возвращает страницу с 200 | один 301 на основной HTTPS без `www` |
| `http://print86.ru/` | отвечает 200 без перехода | один 301 на основной HTTPS |
| `https://print86.ru/` | отвечает 200 без перехода | один 301 на основной HTTPS |
| `http://www.print86.ru/` | нестабильно, получен timeout | один 301 на основной HTTPS |
| `https://www.print86.ru/` | нестабильно, получен timeout | один 301 на основной HTTPS |

Все четыре имени имеют A-запись `31.31.198.55`. Production отвечает через
`nginx`. Punycode кириллического домена:
`xn--80aaarctnodv3agc9d.xn--p1ai`.

До исправления `www.печатаетмаксим.рф` отдаёт ту же страницу с HTTP 200. Тег
canonical указывает на non-www, но серверный редирект отсутствует.

## Требуемая матрица редиректов

Каждое правило сохраняет путь и строку запроса:

| Источник | Код | Назначение |
| --- | --- | --- |
| `http://печатаетмаксим.рф/{path}` | 301 | `https://печатаетмаксим.рф/{path}` |
| `http://www.печатаетмаксим.рф/{path}` | 301 | `https://печатаетмаксим.рф/{path}` |
| `https://www.печатаетмаксим.рф/{path}` | 301 | `https://печатаетмаксим.рф/{path}` |
| `http://print86.ru/{path}` | 301 | `https://печатаетмаксим.рф/{path}` |
| `https://print86.ru/{path}` | 301 | `https://печатаетмаксим.рф/{path}` |
| `http://www.print86.ru/{path}` | 301 | `https://печатаетмаксим.рф/{path}` |
| `https://www.print86.ru/{path}` | 301 | `https://печатаетмаксим.рф/{path}` |

Нельзя сначала переводить HTTP на HTTPS альтернативного домена, а затем на
канонический домен: это создаст цепочку из двух переходов.

## REG.RU: действия владельца

1. Открыть личный кабинет REG.RU → «Домены и услуги» → «Хостинг» → сайт
   `xn--80aaarctnodv3agc9d.xn--p1ai`.
2. В разделе привязанных доменов добавить к тому же сайту:
   `www.xn--80aaarctnodv3agc9d.xn--p1ai`, `print86.ru` и `www.print86.ru`.
3. В DNS-зоне каждого имени проверить A-запись `31.31.198.55`. Не добавлять
   конфликтующие A, AAAA или CNAME одновременно.
4. В разделе SSL выпустить или перевыпустить сертификаты так, чтобы SAN
   включал все четыре имени. Дождаться статуса «Установлен».
5. В разделе перенаправлений создать постоянные перенаправления HTTP 301 по
   матрице выше. В качестве назначения вставить
   `https://печатаетмаксим.рф/`; включить сохранение пути и параметров.
6. Если панель создаёт отдельный переход HTTP → HTTPS перед доменным
   перенаправлением, обратиться в поддержку REG.RU с формулировкой:
   «Нужен один 301 со всех HTTP/HTTPS и www-вариантов доменов print86.ru и
   печатаетмаксим.рф на https://печатаетмаксим.рф с сохранением URI и query,
   без цепочек».
7. После применения проверить главную, `/studio/` и URL с параметром
   `?redirect-check=1` для каждого варианта.

## Яндекс Вебмастер

1. Открыть `webmaster.yandex.ru` → «Добавить сайт».
2. Добавить `https://печатаетмаксим.рф/` и `https://print86.ru/`.
3. Выбрать подтверждение через DNS TXT и скопировать выданное Яндексом значение
   целиком в REG.RU → домен → управление зоной → добавить TXT для `@`.
4. После подтверждения открыть основной сайт → «Индексирование» →
   «Файлы Sitemap» → вставить
   `https://печатаетмаксим.рф/sitemap.xml`.
5. Открыть «Индексирование» → «Переобход страниц» и отправить:
   `https://печатаетмаксим.рф/` и
   `https://печатаетмаксим.рф/studio/`.
6. Открыть «Представление в поиске» → «Региональность» и указать
   Нижневартовск. Использовать ссылку на подтверждённую карточку Яндекс Бизнеса,
   когда она появится.
7. В разделе зеркал убедиться, что главным зеркалом выбран
   `https://печатаетмаксим.рф/`.

## Google Search Console

1. Открыть `search.google.com/search-console` → «Добавить ресурс».
2. Выбрать тип «Домен» и по очереди добавить
   `печатаетмаксим.рф` и `print86.ru`.
3. Для каждого ресурса скопировать TXT-значение `google-site-verification=...`
   в DNS-зону REG.RU для `@`.
4. В ресурсе основного домена открыть «Файлы Sitemap», вставить
   `sitemap.xml` и нажать «Отправить».
5. Через «Проверка URL» проверить главную и `/studio/`, затем выбрать
   «Запросить индексирование».
6. В ресурсе `print86.ru` проверить, что Google видит 301 на основной домен.

## Аналитика и карточки организации

- Подключить Яндекс Метрику после создания счётчика владельцем. В настройках
  указать основной домен `печатаетмаксим.рф` и включить фильтрацию собственных
  посещений. Идентификатор счётчика нельзя придумывать или публиковать заранее.
- Google Analytics не обязателен на первом этапе. Добавлять его стоит только
  при запуске Google Ads или необходимости единой Google-воронки.
- В Яндекс Бизнесе создать или подтвердить организацию «Печатает Максим»,
  выбрать Нижневартовск и указать сайт `https://печатаетмаксим.рф/`.
- Не публиковать адрес, телефон и режим работы до подтверждения владельцем.
- В карточке и социальных сетях использовать одинаковые название, описание,
  логотип, регион и основной URL. После подтверждения профилей добавить их URL
  в `sameAs` структурированных данных.

## Контент и семантика

Текущая одна страница достаточна для связанных услуг печати лент и наклеек:
отдельные пустые посадочные страницы не нужны. Отдельный URL следует создавать
только при наличии самостоятельного продукта, фотографий, условий, цены или
FAQ.

Съедобные леденцы с логотипом не подтверждены текущим каталогом проекта, поэтому
они намеренно не добавлены в метаданные и разметку. Страницу под этот запрос
можно создавать только после подтверждения услуги владельцем.

Контрольные запросы:

- Печатает Максим;
- печатаетмаксим;
- печатаетмаксим.рф;
- печать лент с логотипом;
- брендированные атласные ленты;
- печать наклеек;
- стикеры с логотипом;
- круглые наклейки;
- брендированная упаковка Нижневартовск;
- печать лент и наклеек ХМАО.

## Контроль после публикации

- День 0: проверить матрицу редиректов, SSL, canonical, robots и sitemap.
- Дни 1–3: подтвердить оба домена в поисковых кабинетах и отправить sitemap.
- Неделя 1: проверить отчёты индексирования и запросить переобход ошибок.
- Неделя 2: проверить брендовые запросы и главное зеркало.
- Неделя 4: сравнить показы, клики, индексируемые URL и региональные запросы.
- Далее ежемесячно: контролировать 4xx/5xx, Core Web Vitals, сертификаты,
  дубли хостов и видимость контрольных запросов.
